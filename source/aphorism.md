      **破坏性创新四个基本原则**

      1. 企业的资源分布取决于客户和投资者。

      .. container:: aphorism-quote

        组织或者企业的上下游，决定了自身实现价值的基本逻辑，从而影响了其组织形式、价值观和方法论。

      2. 小市场不能解决大企业的增长。

      .. container:: aphorism-quote

        新兴市场几乎无一例外都是发源于小规模的人群，这点增量放在体量大的企业面前，都是ROI极低的。

      3. 无法对并不存在的市场进行分析。

      .. container:: aphorism-quote

        破坏性创新的需求通常来自并不存在或者尚未形成的市场，良好管理者通常都更偏向于可量化的指标来衡量收益，但这对破坏性创新毫无帮助。

      4. 技术供给可能并不等同于市场需求。

      .. container:: aphorism-quote

        一个技术在发展的后期，其主要功能（例如AI的准确性、硬盘的单位容量、胰岛素的有效性等等）往往表现出超过市场需求的性能，这时市场会表现出对其他功能的新追求，从而给技术的新方向提供了土壤。

        不是说技术的深度没有意义，而是追求技术深度需要承担沉没成本，需要管理者对市场需求和技术成本之间进行有效的衡量，不要企图去过度优化产品的某项性能。

      （《创新者的窘境》）

      **五步工作法**

      Make requirements less dumb
      
      .. container:: aphorism-quote
      
        不要提太蠢的需求。尤其聪明人给的需求更是危险，因为你可能不会去质疑他。大胆地质疑权威，细心验证新方法。

      Delete parts or process

      .. container:: aphorism-quote
      
        删除需求当中所有你能删除的部分和流程，后来可能也会加回来，但如果后来加回来的部分不到 10% 证明删得还不够，奥卡姆剃刀。
      
      Simplify or Optimize
      
      .. container:: aphorism-quote
      
        简化和优化，不要老是在优化根本不该存在的需求，或者使用量低、影响面小的功能。

      Accelerate cycle times
      
      .. container:: aphorism-quote
      
        加速迭代，但前三点沒有做完之前先別加速，否则只是加快了自掘坟墓的速度。注意加速的是迭代，而不是速度。 迭代是一个循环，通过这个循环我们可以不停的验证当前推进的方向，并且持续的进行改进和优化。
      
      Automate
      
      .. container:: aphorism-quote
    
        最后才是自动化。自动化的弊端有三个，分别是高昂的成本、极高的出错几率和妨碍引入新特性。而高效的框架应该是一个可以随时更换组件、流程、探索新特性的并行系统。
      
      (Elon Musk)
